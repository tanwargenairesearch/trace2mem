# Document format preferences

The user's standing default preferences for prepared materials are DOCX format, high contrast, and Finnish language, set in the context of a museum conservation study [cite:leena-001]. The assistant acknowledged retaining these preferences [cite:leena-002]. When the assistant later floated switching a briefing to PNG, the user reaffirmed keeping the original document preferences [cite:leena-014][cite:leena-015]. These preferences remain current and were referenced by the user as applying to briefing preparation [cite:leena-013].
