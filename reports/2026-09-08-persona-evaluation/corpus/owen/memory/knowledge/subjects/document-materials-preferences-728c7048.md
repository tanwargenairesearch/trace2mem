# Document/materials preferences

The user's standing default preferences for any prepared materials are HTML format, large text, and Irish language, established at the start of the planning work [cite:owen-001]. The assistant acknowledged retaining these preferences [cite:owen-002]. When the assistant later proposed switching a briefing to PNG, the user explicitly rejected the change and reaffirmed the original preferences [cite:owen-014][cite:owen-015]. These preferences remain current and were to be applied to the requested briefing [cite:owen-013].
