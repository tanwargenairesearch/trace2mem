# First visit: Reed Rescue, Galway

The first confirmed, approved appointment of the volunteer training tour is a meeting with Reed Rescue in Galway [cite:owen-004]. It was originally set for 2027-03-17 [cite:owen-004] but the user corrected it to 2027-03-20 because the venue is closed for maintenance on the original date; the organization and coordinator were unchanged [cite:owen-010]. The current date is therefore 2027-03-20, and the 2027-03-17 date is historical only [cite:owen-011]. Coordination of this visit is owned by Asha [cite:owen-008]. No hotel has been selected or booked in connection with the meeting location [cite:owen-016].
